# Product image verification

**Where the images come from.** The five catalogue boards supplied by the site owner are stored in `data/source/image-boards/` (a sixth upload was a byte-identical copy of the Home & Kitchen board). `scripts/image-tooling/` crops each board cell, removes the number badge and label, enlarges the product to fill a square and saves `public/products/<SKU>.webp`. `data/image-manifest.json` records, for every image, the board, cell number and the board label it was matched on.

**How products were matched.** By name only. Where the board label equals the product name the match is `exact`; where it is close but not identical (for example “Webcam with Microphone” for “1080p USB Webcam”) it is `similar` and is flagged in the image notes and in `docs/IMAGE_AUDIT.md` so you can confirm it. Board items with no product of that name (strollers, drones, printers, …) are not shown on the store; they are kept in `data/unassigned-board-images/` for future use. No image was assigned to a product it does not belong to; 37 products have no matching image and show the neutral placeholder.

**Status recorded in the database.** Source type `ADMIN_UPLOAD`, source “Owner-supplied Code Crest catalogue board”, permission `PERMITTED` (supplied by the owner), verification `PENDING`. These are not supplier or manufacturer photographs and the origin of the underlying artwork is not documented. Resolution is limited by the board size (about 200 px per item before enlargement), so they look soft at large sizes; supplier photos will be sharper.

**Managing images.** Admin → Images lists every product with its image state (also `GET /api/v1/admin/images/report`). To add or replace an image open the product, upload a JPEG/PNG/WebP (≤5 MB), record the source and permission, and set verification once checked. Only use images you own, have written permission for, or have licensed.
